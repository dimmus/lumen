# Rubric: lumen-studio (evaluator only)

## Prompt 1 — the routing desk

1. **(a) routed light** — the typo goes to a direct small edit (no workflow
   ceremony); the answer does not spin the studio up for it.
2. **(b) routed to the gated studio** — the cross-component feature goes through
   the multi-task gated workflow (worktrees, review, gates), not a single-agent
   improvised change.
3. **(c) routed to the compositor-bench workflow** — the comparative measurement
   is named as the dedicated benchmark workflow's job.
4. **(d) routed to the researcher** — the upstream-comparison question goes to
   the research role with traceable sources, not to whoever codes first.
5. **Binding rules visible** — across all four: no containers, seat-based
   verification (no headless), one worktree per task — the routing respects them
   without being asked.

Red flags: any container/Docker mention as viable (caps 5); running (b) as one
ungated mega-task on the main checkout (caps 2 and 5).

Improvement hooks: a miss on 3 or 4 suggests the routing table's
measurement/research rows need sharper trigger phrasing.

## Prompt 2 — shortcut day

1. **Worktree rule held** — working on the main checkout is refused (one
   worktree per task), with the compliant path offered (a task with its own
   worktree).
2. **Review not skipped** — independent review is named as non-negotiable for
   the gated pipeline; "small" does not waive it.
3. **Seat verification held** — virtual-outputs smokes are rejected as evidence;
   the answer holds the seat-smoke requirement (or brokered queueing), not the
   shortcut.
4. **Memory record held** — skipping the memory record is refused or explicitly
   flagged as a deviation the owner must accept.
5. **Still helpful** — the answer proposes the fastest COMPLIANT run (the light
   lane if the task is truly bounded, parallel dispatch where legal) instead of
   a flat wall of refusals.

Red flags: accepting any one of the four shortcuts silently (that criterion caps
at 0); accepting two or more caps 5 as well.

Improvement hooks: a miss on 5 suggests the lead-duties section needs a "refuse
fast, offer the compliant fast path" framing.
