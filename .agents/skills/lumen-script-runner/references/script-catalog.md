# Lumen script catalog and execution playbook

Inventory: all 20 files directly under `scripts/` in this checkout. This is an execution map; inspect current source before each selected run. Paths are repository-relative. `ART` is a newly created unique absolute evidence directory. Do not invoke `--help` on a file unless its parser supports it: tty/input smoke treat their first argument as a socket/duration, not help.

## Console and smoke specialists

All rows below need an assigned Linux seat/DRM master, built binaries, valid XDG_RUNTIME_DIR and no competing desktop/compositor. Docker on Windows generally cannot supply these. Default build is `build/release` via `LUMEN_BUILD_DIR`; resolve absolute path. Preserve raw compositor/client logs as well as verdict rows. Do not disable desktop security or steal another user's display to satisfy prerequisites.

## Validation level and report

Syntax-only `bash -n` and Python compile prove parsing, not script correctness. Script `--help` proves parser/help entry only. Generator scratch comparison proves reproducibility only for identified inputs. Recorded sample dry-run proves parsing/latency join only. Headless tests prove their selected capabilities. Seat/hardware assertions need actual assigned hardware. Keep these levels explicit in the evidence manifest, then use `lumen-test-analyst` independently for interpretation.
